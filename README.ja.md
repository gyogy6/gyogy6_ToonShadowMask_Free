# gyogy6 Anime Shadow Mask（無料版）

[English](README.md) / **日本語** / [简体中文](README.zh-CN.md) / [한국어](README.ko.md)

Substance 3D Painter 用のジェネレーターです。
光の向きを指定すると、アニメ調（セル調）のくっきりした影の範囲を、白黒のマスクとして作ります。
レイヤーのマスクに入れるだけで使えます。

## 2. 動作環境

- Adobe Substance 3D Painter
- 影を付けたいモデルに **UV が展開されていること**

## 3. インストール

1. Painter の上部メニューから **File → Import resources** を開きます。
2. **Add resources** を押して `gyogy6_anime_shadow_mask.sbsar` を選びます。
3. 一覧に追加されたファイルの種類を **generator** にします。
4. 取り込み先を選びます。
   - 今のプロジェクトだけで使う場合：**Current session** または **Project**
   - すべてのプロジェクトで使う場合：自分用のライブラリ
5. **Import** を押します。
6. アセット画面（シェルフ）の **Generators** に **gyogy6 Anime Shadow Mask** が表示されれば完了です。

## 4. 事前準備：メッシュマップのベイク（プロジェクトごとに 1 回）

このジェネレーターは、Painter がベイクしたメッシュマップを使って影を作ります。

1. **Texture Set Settings** パネルの **Bake Mesh Maps** を押します。
2. 次の 2 つにチェックが入っていることを確認します。
   - **World space normal**（光の向きの計算に使います。**必須**）
   - **Ambient occlusion**（くぼみを影にするのに使います）
3. **Bake selected textures** を押して、ベイクが終わるまで待ちます。

## 5. 使い方

### 5-1. 影のレイヤーを作る

1. レイヤーパネルで **Add fill layer** を押します。
2. 作ったレイヤーで、**Base Color 以外のチャンネルをすべてオフ** にします。
3. **Base Color** に影の色を設定します。
   グレーより少し色味のある色（肌なら赤み、服なら青紫寄りなど）のほうが、濁らないアニメらしい影になります。
4. ブレンドモードを **Multiply**（乗算）にします。

### 5-2. マスクにジェネレーターを入れる

1. レイヤーを右クリックし、**Add black mask** を選びます。
2. マスクを右クリックし、**Add generator** を選びます。
3. ジェネレーターの選択欄で **gyogy6 Anime Shadow Mask** を選びます。
4. 影の部分にだけ色が乗れば成功です。

### 5-3. パラメーター

| 項目 | 意味 | 目安 |
|---|---|---|
| **Light Horizontal (deg)** | 光がどの方向から来るか（0〜360°）。0 はモデルの正面からです。 | 30〜60 |
| **Light Vertical (deg)** | 光の高さ（-89〜89°）。大きいほど上から当たります。 | 20〜50 |
| **Shadow Amount** | 影の広さ。上げると影が広がります。 | 0.4〜0.6 |
| **Feather** | 影の境目のぼかし幅。小さいほどくっきりします。 | 0.01〜0.05 |
| **AO Influence** | くぼみ（脇、首の下、服の重なりなど）を常に影にする強さ。 | 0.3〜0.8 |
| **Invert (lit side)** | 1 にすると、影ではなく光が当たる側が白になります。ハイライト用です。 | 0 |

### 5-4. ヒント

- **濃い影（2 影）を足す：** 同じ手順でレイヤーをもう 1 枚作り、**Shadow Amount を小さめ（0.1〜0.3）** にします。
- **手描きで直す：** マスクの中でジェネレーターの上に **Paint** を追加し、白（影を足す）や黒（影を消す）で描きます。
- **ハイライト：** **Invert** を 1 にしたレイヤーを作り、ブレンドモードを **Screen** にします。

## 6. うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 一覧に gyogy6 Anime Shadow Mask が出ない | 取り込むときに種類を **generator** にしたか確認してください。違う種類で取り込んだ場合は、削除してから取り込み直してください。 |
| 影が真っ黒、または何も出ない | メッシュマップのベイク（4 章）が終わっているか確認してください。特に **World space normal** が必要です。 |
| 光の向きが思った方向と違う | Light Horizontal / Light Vertical を調整してください。 |
